# Calculator
## ${\color{orange}\text{Concept explanation}}$:
Explanation:
```
    The program allows the user to perform arithematic operations with two numbers and loops again the
    process until the user refuses to continue.
```
The program receives input:
```
    (1) First number.

    (2) Mathematical operator.

    (3) Second Number.

    (4) Choice to repeat using the calculator program.
```
<br>

It outputs:
```
    (1) The value resulting from the mathematical operation.
```
<br>

Rules: 
```
    (1) Illegal division by zero
```
