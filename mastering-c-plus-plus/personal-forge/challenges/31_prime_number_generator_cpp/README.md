# Prime Number Generator:
## ${\color{orange}\text{Concept Explanation}}$:
Explanation: <br>

The `Prime Number Generator` is about genetrating the number of primes found until reaching user's limit boundaries.
````
    For example:

        number: 9
        Primes found till (9): [3, 5, 7]

        number: 23
        Primes found till (23): [3, 5, 7, 11, 13, 17, 19, 23]
````
