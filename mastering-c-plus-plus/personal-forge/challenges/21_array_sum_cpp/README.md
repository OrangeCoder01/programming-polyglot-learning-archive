# Array Sum
## ${\color{orange}\text{Concept explanation}}$:
Explanation:
```
    The program sum user input elements inisde an array and outputs the total summation beside the array.
```
The program receives input:
```
    (1) number of elements.

    (2) each element's numerical integer value.
```
<br>

It outputs:
```
    (1) The printing of the sum of all elements' values in array
```

<br>

Rules: 
```
    (1) Maximum 10 elements and minimum of 1.

    (2) Values must be in range [-65535 ~ 65535].
```
for ${\color{pink}\text{example}}$:
```
    Please, Enter the number of elements/numbers: 6
    Insert the values of your elements/numbers individually:

    Enter value for element {0}: 23
    Enter value for element {1}: 56
    Enter value for element {2}: 34
    Enter value for element {3}: 86
    Enter value for element {4}: 34
    Enter value for element {5}: 2

    Array: [23, 56, 34, 86, 34, 2]  The sum is 235
```
