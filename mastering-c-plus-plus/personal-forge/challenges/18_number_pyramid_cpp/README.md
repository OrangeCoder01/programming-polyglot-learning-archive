# Number pyramid
## ${\color{orange}\text{Concept explanation}}$:
Explanation:
```
    The program receives the number of rows the user input and the program print a Number pyramid.
```
Input:
```
    (1) The number of rows of the Number pyramid from the user.
```

Output:
```
    (1) The Number pyramid with the given the number of rows.
```
