# ${\color{orange}\text{Code Explanation:}}$

'Armstrong Number' ${\color{yellow}\text{challenge:}}$ is about taking an input integer, count the number of digits, separate each digit and then power each digit by the power of number of digits
<br>
sum all together, if the sum is the same as the integer, then the integer is an 'Armstrong number'.
<br>
${\color{pink}\text{For example}}$: 370 ➡️ 3 7 0 ➡️ num. of digits = 3 ➡️ 3³ + 7³ + 0 = 27 + 343 + 0 = 370 ➡️ return it is an 'Armstrong Number'
