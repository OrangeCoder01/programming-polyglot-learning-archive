# ${\color{turquoise}\text{Arduino}}$ development board brand:
${\color{turquoise}\text{Arduino}}$ brand is famous for being `beginner friendly` development board brand, personally my first MCU was from an ${\color{turquoise}\text{Arduino}}$ brand.
<br>The folder is composed of the `MCU family tree` of ${\color{turquoise}\text{Arduino}}$, currently including `Arduino UNO (arduino-uno)`.
<br>
<br>The MCU labeling is simple but expansive, UNO is a sub-family parent on its own, adopting `UNO R1`, `UNO R2`, `UNO R3`, and others.
<br>later when the folder got overlapping MCUs labels, a new folder will be brought up to differentiate between the sub-families.
