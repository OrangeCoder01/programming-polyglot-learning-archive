# ${\color{red}\text{Projects}}$ folder:
This folder consists of `levels of difficulty` folders that each contain multiple
<br>${\color{red}\text{Projects}}$ that are ranked by the level difficulty.
<br>The criterion for assessing ${\color{red}\text{Project}}$'s difficulty:
<br>1) `Algorithmically challenging`: How the output hardware behavior is achieved with respect to the strategy/approach.
<br>2) `Programming skills`: Is the implemented uses advanced ${\color{purple}\text{programming language}}$ features.
<br>3) `Hardware connection`: The software may be easy, but the hard may not.
