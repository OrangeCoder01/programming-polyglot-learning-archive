# Task 2:
Problem:
````
    (2) C Function to find length of a given string using pointer.
````
Explanation:
````
    The program manages a char array filled with user's string name,
    where it returns the length of the name.

    For every char array, the edge is '\0' called as "Null terminator"
    responsible for declaring the end of the string.
````
|Input|Output|Obligation|
|:--- |  :---|      :---|
|(1) Name (string)|(1) The length of the name (integer)|(1) string before the space is only stored.|

Why building this program:
````
    Implemnenting Null terminator in char array and pointers.
````
