# Lab (2):
Question:
```
    Take grades of 3 students from 4 exams, make a function to get the lowest and highest grades.
```
Explanation:
```
    The program uses 2D with 3 rows as number of students and 4 exams as columns,
    each row has 4 columns; each student had been examined in 4 exams.

    Processing the 3 row and 4 column array, the output the smallest mark possible in the
    whole array.
```
<br>

|Input:         |Output:        |
|---------------|---------------|
|(1) The mark of each student in each exam (integer)|(1) The smallest mark among all marks.

<br>
<br>

Why building this program:
```
    Implementing multi-dimensional (2D) array with derefencing and pointers arithmetics.
```
