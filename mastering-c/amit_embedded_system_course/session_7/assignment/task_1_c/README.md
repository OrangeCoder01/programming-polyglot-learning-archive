# Task 1:
Question:
```
    (1) Write a C program to print the index of FIRST occurrence of
        a number in an array. Array index start from 0. If the item is not
        in the list print -1.
    
        Example:
        Array = {1,2,3,4,4,4}
        The required number is 4 it should print 3
```

Explanation:
```
    The program proceeds an array of user inputed elements' value, and the target element's value, and the program
    returns the index of the first occurence in the array with the same value of the target's.
```
<br>

|Input:                               |Output:                              |Rule:|
|-------------------------------------|------------------------------------ |-----------------------------------------------------------------------|
|(1) The size of the array. (integer) |(1) The index of the first occurence + array (text + integer)              |(1) The value of the elements' value must be between (-60,000 ~ 60,000)|
|(2) The elements' value.   (integer) |(2) "Number is not found!" if no occurence + array (text + integer)|(2) The size of the array between (1 ~ 100).
|(3) User's searched number.(integer) |
