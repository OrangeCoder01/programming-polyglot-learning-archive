# Assignment session (8):
Implemented
```
    (1) Functions with array as parameter.

        Returning the arrays as pass by reference in a function with return type void.
    
    (2) Why using arrays in functions:

        It is a important as inserting any other parameteric input to a function, to process the
        elements inside that array and returning the changing that is done to the array as a pass
        by reference.

        Array are passed by reference by default, as pass by value method will consume a lot of processing
        power for the simple copy-pasting of an array that have larger size.
        Pass by reference operates on changing the array itself without copy-pasting the content.
```
