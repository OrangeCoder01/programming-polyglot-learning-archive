# Task 1:
Question:
```
    (1) Write a function called total, which totals the sum of an
        integer array passed to it (as the first parameter) and returns
        the total of all the elements as an integer. 
        
        Let the second parameter to the function be an integer which contains the
        number of elements of the array.
```

Explanation:
```
    This program inserts the array and its size to a function that returns the sum of the elements of the
    array.
```
<br>

|Input:                           |Output:                        |Rules:                                                |
|---------------                  |---------------                |-----------                                           |
| (1) The size of the array       |(1) Sum of elements in an array|(1) Size must be between (1 ~ 100)                    |
| (2) The elements' value in array|                               |(2) Element's value must be between (-60,000 ~ 60,000)|

<br>
<br>

Why building this program:
```
    For practising implementation of functions with array as a parameter.
```
