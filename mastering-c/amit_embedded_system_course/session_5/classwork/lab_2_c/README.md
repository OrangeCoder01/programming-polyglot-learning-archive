# lab (2):
Question:
```
    Create an arbitrary password, let the user insert the password; giving 3 trial,
    if user wasted all the trial chances; exit the program, otherwise indicate the password
    is correct.
```
Explanations:
```
    The program checks if the user's inserted password mathces the correct password
    while providing 3 trials.
```
Input:
```
    (1) The password pin (integer).
```
Output:
```
    (1) Text indicating either:
        (1.1) Correct user's inserted password.

        (1.2) Exiting due to no trial chances left.

        (1.3) Incorrect user's inserted password, and asking for try-again.
```
Why building this program:
```
    For building a program with integrating iterative and conditional control flows
```
