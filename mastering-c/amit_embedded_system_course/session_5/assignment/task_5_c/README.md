# Task 5:
Question:
```
    (5) Write a C function that returns 1 if the input number is a
        power of 2 and return 0 if the input number is power of 3,
        otherwise it shall return -1.
```
Explanation:
```
    The program a number input prompted by the user, return integer representation of states:

        return 1 if the number is of a result of power exponentiation of 2.
        return 0 if the number is of a result of power exponentiation of 3.
        return -1 if the previous two cases are false.
```
Input:
```
    (1) A number (integer).
```
Output:
```
    (1) printing text indicating if the input number a result of power exponentiation of 2, 3, or else (text).
```
Why building this program:
```
    For solving algorithmically challenging problem.
```
