```

        arguments.

        return error.

```
    The program performs "Calculator" program's basic arithmetic operations with two input numbers, looping
    the mathematical operation as the user requested, and exiting in case the user asked to exit.
```
Input:
```
    (1) 2 numbers: first and second operands (float).
    (2) A mathematical operator (char).
```
Output:
```
    (1) Printing the result of the mathematical operation (text + float + char).
```
Why building this program:
```
    Implementing the first integrated program that function as a true simple calculator using
    C programming language.
