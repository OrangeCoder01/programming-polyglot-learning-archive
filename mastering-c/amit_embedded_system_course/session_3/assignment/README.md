        (1.3) Multiplication.
        (1.4) Division.
        (1.5) Modulo.

    (2) printf() function:
        (1.1) Text string.
        (1.2) Format specifier (data type placeholder).
        (1.3) Floating point precision.
    
    (3) Data type declarations:
        (3.1) int.
        (3.2) char.
        (3.3) float.
    
    (4) Bit manipulation:
        (4.1) Basic bit manipulation:
            (4.1.1) Shift bit right.
            (4.1.2) Shift bit left.
        
        (4.2) Tool bit manipulation:
            (4.2.1) Clear bit (set bit to zero).
            (4.2.1) Check bit (check the boolean of the bit).
    
    (5) Bitwise operations:
        (5.1) Bitwise AND.
        (5.2) Bitwise OR.
        (5.3) Bitwise XOR.
    
    (6) Basic Pre-processor directive:
        (6.1) #define.

    (7) Why is this assignment important:

        For understanding the implementations of basic arithmetics, bitwise operations,
        typecasting different data types, bit manipulations of a binary number representation
        of an integer.
