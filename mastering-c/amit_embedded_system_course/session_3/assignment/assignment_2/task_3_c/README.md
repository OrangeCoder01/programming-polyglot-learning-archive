# Task 3:
Question:
```
    (3) Write a program that asks the user to enter a three-digit
        number, separates the number into its individual digits and print
        the digits separated from one another by three spaces each.

        [Hint: Use combinations of integer division and the remainder
        operation.] 

        For example, if the user types in 421, the program
        should print: 4 2 1
```
Explanation:
```
    The program prints seperated digits of three digit integer input from the user.
```
Input:
```
    (1) Three digit input integer from the user.
```
Output:
```
    (1) The printing of the three distinct digits.
```
Why is this program important:
```
    Implementing the modulus and the division arithmetic operators for
    digit seperation from an integer.
```
