# Task 5:
Question:
```
    (5) Write a program to add two floating numbers.
        Determine the integer floor of the sum. 
        
        The floor is the truncated float value, anything after the decimal point is
        dropped.
```
Explanation:
```
    The program converts the sum of two float numbers as integers.
```
Input:
```
    (1) 2 numbers (float).
```
Output:
```
    (1) The printing of the sum of the two float numbers as an integer and the two numbers.
```
Why building this program:
```
    Implementing type casting as a method for float fraction suppression,
    and floating point precision ("%.2f") in printf().
```
