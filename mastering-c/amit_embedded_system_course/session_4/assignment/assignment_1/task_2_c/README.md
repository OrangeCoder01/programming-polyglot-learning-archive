# Task 2:
Question:
```
    (2) Write program that converts any letter from
        lowercase to uppercase.
```
Explanation:
```
    The program converts lowercase alphabets to uppercase alphabets.
    For example:

        a     ---> A
        (65)  ---> (97)
```
Input:
```
    (1) The lowercase alphabet.
```
Output:
```
    (1) The uppercase alphabet corresponding to the input alphabet.
```
Why building this program:
```
    Implementing the ASCII distance between lowecase and uppercase alphabets,
    which is (97 - 65) = 32 decimal point apart.
```
