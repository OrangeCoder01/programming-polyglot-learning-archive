# Task 1:
Question:
```
    (1) Write a program that takes one character and checks if it alphabet or not.
```

Explanation:
```
    The program process a user's input character, if it is an alphabetical character: it outputs an indication for it being a character
    or not.
```
Input:
```
    (1) An input character from the user.
```
Output:
```
    (1) Text indicating that typed character being an alphabetical character or not.
```
Why building this program:
```
    Implementing Conditional Control flow to filter the within Alphabetical decimal ASCII range:
    (97 ~ 122) and (65 ~ 90).
```
