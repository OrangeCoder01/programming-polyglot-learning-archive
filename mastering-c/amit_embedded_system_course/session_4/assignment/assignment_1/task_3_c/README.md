# Task 3:
Question:
```
    (3) Write a program that reads two integers and checks
        if the first is multiple of the second.
```
Explanation:
```
    The program checks if the user's first input integer is a multilpe (being multiplied by an "integer" factor in order to be
    equivalent to the second number) of the second number.
    For example:

        3 is a multiple of 18 by a multiple of 6:

            3 * 6 = 18

    Another example:

        4 is not a multiple of 18:

            4 * 3 = 12
            4 * 4 = 16
            4 * 5 = 20

            4 * 4.5 = 18 (4.5 is not an integer).
```
Input:
```
    (1) 2 input number (integers).
```
Output:
```
    (1) printed text indicating if the the first number a multiple of the second.
```
Why building this program:
```
    Gaining practical understanding of modulus and division operators in mathematics.
```
