# Classwork Session (4):
Implemented:
``` 
    (1) Control Flow (loops)

        (1.1) Iterative control flow:
            (1.1.1) Condition-based iterative control flow:
                (1.1.1.1) while(){} loop (Boolean controlled repetitions) keyword.

                    Loop breaks when the conditional statement is false.

            (1.1.2) Counter-base iterative control flow:
                (1.1.2.1) for(){} loop (Numerical controlled repetitions) keyword:

                    Loop breaks when an iteration breaks a conditional statement regarding the iteration.

                    (1.1.2.1.1) Declaration and initialization of control variable.
                    (1.1.2.1.2) Test condition.
                    (1.1.2.1.3) Iterative or deiterative step.    


        (1.2) Conditional cotrol flow:
            (1.1.2) Main keywords
                (1.1) if(){}
                (1.2) if else(){}
                (1.3) else(){}
                (1.4) switch()case{}
    
    (3) Why learn Control flow:

        To control how the compiler reads and process the data, thus yielding to developer's
        specificied output.
```
