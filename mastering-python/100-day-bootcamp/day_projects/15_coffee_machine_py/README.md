# Coffee Machine
## ${\color{orange}\text{Concept explanation}}$:
"Coffee Machine" project is about programming a virtual coffee machine that asks the user two types of questions:
<br>1) `Would you like to drink coffee: (espresso, latte or cappuccino)`
<br>2) `Insert the number of coins: (Quarter, Dime, Nickel or Penny)`
<br>
<br>The program :
<br>[1] takes those inputs, 
<br>
<br>[2] proceeds with stored data: 
<br>(provisional sustainability: `(water, milk, coffee)`, data tracking: `(refilling, consuming and reporting the provisions)`, validity of input: `(user's input must be integer upon inserting coins, float when refilling the provision and string when asking for a product`))
<br>
<br>and finally [3] output meaningful result based on data ${\color{pink}\text{example}}$: `Here is your coffee, enjoy`, `Unfortunately, there is insufficiency, the provisions inside the machine needs to be replenished`.
