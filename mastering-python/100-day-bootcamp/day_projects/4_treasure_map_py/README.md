# Treasure Map
<details>
<summary><b>What is Treasure map:</b></summary>
<br>

The game `Treasure map` is a story made for creative personal storytelling using ASCII shapes copied from external websites for visual stimulation. 
<br>
</details>


<details>
<summary><b>How is Treasure map built:</b></summary>
<br>

The user either presses **`enter`** bottom to proceed to the next line of the story or insert string literal such as "yes" or "no" for criticial decision making amid the game.
<br>

</details>


<details>
<summary><b>Why build Treasure map:</b></summary>
<br>

Implementing large string literals called **`ASCII art`** shapes and inserting them in a story game.
<br>

</details>
