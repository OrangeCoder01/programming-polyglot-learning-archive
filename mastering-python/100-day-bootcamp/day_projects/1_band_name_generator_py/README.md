# Band Name Generator 
What is `Band Name Generator` project:
````
    The project is about generating a creative name of a band
    by concatenating two string inputs from the user: one for the name of the
    city the user grew up in, and user's pet's names.
    For example:
````
```py
        city_name = input("Please, What is the name of the city you grew up in?\n") # Helsinski 
        pet_name = input("Please, what is your pet's name?\n") # Chub 
        band_name = city_name + " " + pet_name # Helsinskin Chub
```

Why build `Band Name Generator` project:
````
    Implementing string concatenation.
````
|${\color{blue}\text{Input}}$: |${\color{red}\text{Output}}$: |
|:---|:---|
|(1) **City**, and **Pet** **names** (string) | (1) The creative **band name** (string)|
