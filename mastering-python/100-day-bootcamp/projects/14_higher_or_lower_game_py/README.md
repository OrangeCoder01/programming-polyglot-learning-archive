# ${\color{red}\text{Higher/Lower Game}}$
## ${\color{orange}\text{Concept Explanation}}$
<br>Higher/Lower game ${\color{red}\text{project}}$ is about guessing which celebrity has the higher amount of followers
<br>The game dynamic is initialized by selection two randomly celebrities out of a list: comparing celebrity A<br>
and compared-to celebrity B.<br>
<br>
celebrity A becomes B, and B is randomly chosen from the list in the next round. <br>
<br>
If the user's guess is correct, the game continues and score increases,  until the user make a wrong
<br>assesment and thus expeled, then asked whether he/she would like to play again whilst keeping track of <br>their 'all time high score'.
<br>
<br>During the game, the comparing celebrity is switched to the other celebrity regardless having higher or <br>lower number of followers
