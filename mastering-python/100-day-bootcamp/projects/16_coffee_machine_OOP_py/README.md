# Coffee machine (using OOP: Object Oriented Programming)
## ${\color{orange}\text{Concept explanation}}$:
This project is about making a `coffee serving` program that manages user input, validate the input, analyze the input then from
the analyzed data, the expected output is produced.
<br> It is the first code file that includes the use of `Object Oriented Programming` in ${\color{orange}\text{Python}}$ in ${\color{purple}\text{programming language}}$
<br>Unlike `Procedural Programming` where there is separation between data and functions; the `OOP` manages to integrate both by
<br>by using features as `objects`, `attributes`, `methods` and `classes`.
