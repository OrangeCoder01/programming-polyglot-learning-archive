# Day 17:
## ${\color{orange}\text{Concept explanation}}$:

Learned
```
    (1) Deeper understanding of OOP and its concepts:
        (1.1) Classes:
            (1.1.1) Attributes:
                It is the inherent characteristics of the object, thet are data (variables).
                such as: number of wings (integer), has the ability to walk (boolean), name (string), academic GPA (float), and etc...

            (1.1.2) Methods:
                It is the "what" the object can do in data manipulation (functions).
                such as: draw(), write(), swim(), and etc...


            (1.1.3) Self:
                It is a generic name for any object that is undergoing change in its attributes (intrinsic characteristics)
                or performing an action (methods or functions).
                    for example:

                        Bob and Anika are objects from class "Human" which both have the attribute of "money":
                        
                        Bob earned 20 dollars and Anika lost 30 dollars.
                        The class "Human" blueprint uses self where whatever object is, it adds or removes money from it.
                        
                        Bob = Human()
                        Anika = Human()

                        Bob.money += 20
                        Anika.money -= 30



            (1.1.4) Initialization: "__init__()":
                It is the very function that gets executed upon declaring an object of the class that holds the initialization.
                It as setting the default setting of attributes.
                    for example:

                    number of eyes of humans are by default is 2.
                    The "__init__" in "Human" class has:
                         self.number_of_eyes = 2



        (1.2) Objects.
            It is the product from the class (blueprint).


    (2) Name case in programming:
        (2.1) Pascal case:
            The first letter for any word is capitalized.
                for example:

                    AnimalKingdomInMesopotamia
        
        (2.2) Camel case:
            First letter of the first word is small, then the first letter for any of the following words are all capitalized.
                for example:

                    animalKingdomInMesopotamia
            
        (2.3) Snake case:
            All lettesr are in small case and the words are seperated by underscore
                for example:

                    animal_kingdom_in_mesopotamia
        
```
