# Microelectronics Design Tools Course

This is course was taken in 2026 in my penultimate year (4th year), this course is about `Learning digital logic gates and implementing logic by writing the Hardware Descriptive Language (HDL)`.
<br>

## Content
The topics from this course span from simple Gate: AND, NOT, etc. to learning registers: D Flip Flop, D Latch, thus introducing `Synchrounous` and `Asynchronous` registers (including Clock cycle, Enable pin, Reset pin), then to Conditional logic using (`when else`, or `with select`, or `case`) implementing Truth table and Lookup tables, then to switching between Sequential and oncurrent behavior, implementing modularity by applying component behaviors into larger ones such as using `half-adder` in `Full-adder`, passing through `FSM`(Finite State Machine), and later approaching more complex concepts.
<br>

## The Objective of this course is to: 
```
    [1] Have a better understanding of the digital System: "Computer" as an example, by grasping through the three middle layers:
        (1) Subsystems (Processor, Memory, Peripherals, and IO)
        (2) Blocks (Adders, Registers, Control Logic, Buses)
        (3) Logic Gates (AND, OR, NAND, or NOT)

        Thus having transcendent comprehension above the electronic intricacies of the "Transistor Level" and more technical in-depth than the utmost layer: 
        "Digital System (MCU/FPGA)"

    [2] Gain skills in using VHDL (Verilog Hardware Descriptive Language) through the Vivado (version 2018) software which helps the student:
        (1) To find ease when continuing to learn a more advanced comprehensive course (having a solid background on basics) outside the College's Course Curriculum.
        (2) To be a suitable candidate when pursuing the carriers associated with electronics and digital system engineering.
```
<br>
